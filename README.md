# TellurOm Portfolio

Build a **premium, modern, production-quality personal portfolio website** for **TellurOm**, a B.Tech CSE (Cyber Security) student at ITM Skills University.

This website is being submitted for the **Student Portfolio Hackathon 2026**, where it will be evaluated by an industry panel.

The most important instruction:

> **DO NOT make this look AI-generated.**
>
> Do not use generic AI portfolio patterns, outdated gradients, neon hacker colors, excessive glassmorphism, excessive rounded cards, fake terminal animations, Matrix rain, hacker skulls, random binary numbers, or "cyberpunk" visual clichés.

The website should look like a **real portfolio designed by a strong frontend developer/UI designer in 2026**.

It should be something TellurOm could continue using for internships and placements after the hackathon.

# 24. MOTION DESIGN

Use animation, but make it feel expensive.

Good:

- fade/slide section reveals
- smooth page transitions
- subtle text movement
- project hover interactions
- line animations
- network-node movement
- image masking
- navigation transition
- subtle button interactions

Bad:

- constant glowing
- spinning objects
- excessive particle systems
- cursor-following blobs
- giant parallax
- bouncing text
- glitching everything
- animation on every card

The animation should be noticeable only when interacting with the website.

### Technical

# 35. MOST IMPORTANT DESIGN PRINCIPLE

Do NOT try to impress the judges by adding as many effects as possible.

Instead make them think:

> "This looks like a portfolio that could belong to a real junior security engineer."

The website should feel:

**quietly impressive rather than loudly impressive.**

Use typography, spacing, layout, interaction and content hierarchy to create the wow factor.

The final product should be **clean, modern, distinctive, technically credible, responsive and genuinely usable after the hackathon.**

Build the complete website, run it, inspect it visually, and refine it before considering the implementation complete.
